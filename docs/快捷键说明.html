LANGOS 快捷键总表

MINILOONG Pocket1（RK3566 / Debian 13）· 核查日期 2026-09-16 数据来源：设备现役文件（/home/ark/.config/retroarch/retroarch.cfg 与 retroarch32/retroarch.cfg、 /usr/local/bin/ogage、/opt/vagaretro/native/vgfront 的按键分派代码）。 两份 RA 配置的热键完全一致，所以游戏是走 RA 还是 RA32 都是同一套按法。

按键分三层，互不干扰：前端界面（LANGOS）、游戏里（RetroArch）、系统级（ogage 全局热键）。 游戏里前端是退出的，所以前端的 Y 搜索 / START 设置那几项在游戏中按不出来 —— 这是设计如此，不是坏了。

💡 机器上就能看：设置 → 快捷键说明 里有同样一份（可滚动，↑↓ 滚、L1/R1 翻页、B 返回）。 那一页是 vgfront 自己画的（纯 C，不依赖任何外部文件），随系统语言切中英。

音量不归 RA 管 —— 用机身上的音量键（见第三段）。RA 配置里 volume_up_btn / volume_down_btn 都是 nul。

快进是 2026-09-16 才加到 L2 / R2 上的（原本 L2 / R2 是亮度，亮度挪到了十字键上 / 下）。 RA 的快进属于热键，必须挂在门禁键后面，所以按法是 M + L2 而不是单按 L2。 那次改的只有 hold_fast_forward / toggle_fast_forward / brightness_up / brightness_down 四项，门禁 input_enable_hotkey_btn 始终是出厂的 "10"（M）—— 所以上面整套 M + XXX 一个都没动。 铁律仍然成立：前端一个 RA 热键的字节都不写，改的是设备上的 retroarch.cfg。

四、几点说明

  • 出不来游戏怎么办：先按住 M 再按 START。这是唯一可靠的退出口，前端在游戏里不响应任何按键。
  • RA 菜单里改的东西（金手指、核心、遮罩、连发）是 RA 自己的存档，跟前端无关；

前端弹层里的核心 / 着色器 / 存档位是启动参数，只影响"下次怎么启动这个游戏"。

  • 前端接管的启动链路：前端按下"启动游戏"后自己退出，屏幕交给 RetroArch；游戏退出后启动器再把前端拉起来。

所以游戏中看到的画面全是 RA 的，前端设置页按不出来。

  • SELECT 退出前端这个功能 2026-09-15 已经撤掉（前端接管链路后，退出去只会被原地拉起、白丢续页状态）。

真要退出/关机走「设置 → 电源 / 退出」。
