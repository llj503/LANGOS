> MINILOONG Pocket1（RK3566 / Debian 13）· 核查日期 2026-09-16
> 数据来源：设备**现役**文件（`/home/ark/.config/retroarch/retroarch.cfg` 与 `retroarch32/retroarch.cfg`、
> `/usr/local/bin/ogage`、`/opt/vagaretro/native/vgfront` 的按键分派代码）。
> 两份 RA 配置的热键**完全一致**，所以游戏是走 RA 还是 RA32 都是同一套按法。

## 一、前端界面（LANGOS：主页 / 游戏列表 / 弹层 / 设置页 / 搜索页）

| 按键 | 主页 | 游戏列表 | 操作弹层 | 设置页 | 搜索页 |
| --- | --- | --- | --- | --- | --- |
| 方向（十字键或左摇杆） | 挪卡片 | 挪卡片 | 上下选功能 | 上下选行、左右改值 | 挪光标 |
| **A** | 进入该平台 | 打开操作弹层 | 确认 | 确认 / 进子页 | 软键盘上=输入；结果上=打开弹层 |
| **B** | 无动作 | 回主页 | 返回（删除待确认时=取消） | 返回上一级 | 结果区=回软键盘；软键盘=退格；输入为空=回主页 |
| **Y** | 打开搜索 | 无动作 | 被弹层吞掉 | 不响应 | 无动作 |
| **L1 / R1** | 顶栏分类左右切 | 无动作 | 被吞掉 | 被吞掉 | 被吞掉 |
| **START** | 打开设置页 | 无动作 | 被吞掉 | 返回上一级 | 清空输入 |
| **SELECT** | 无动作 | 无动作 | 被吞掉 | 返回上一级 | 返回 |
| **X** | 前端界面里没有功能（留给 RA） | | | | |

操作弹层里的 7 项，顺序固定：

| 项 | 按 A 之后 |
| --- | --- |
| 启动游戏 | 立刻启动（前端退出，屏幕交给 RetroArch） |
| 收藏游戏 | 加入 / 取消收藏（主页会出现「我的收藏」） |
| 更换模拟器核心 | 展开候选列表：↑↓ 选、**←→ 切「仅本游戏 / 整个平台」**、A 确认、B 返回 |
| 着色器效果 | 展开候选列表：↑↓ 选、A 确认、B 返回（这个列表**没有 ←→**），只对当前核心生效 |
| 加载存档 | 展开 5 个存档位：↑↓ 选、A 确认、B 返回（也**没有 ←→**）。选一位 → **下次启动游戏时**自动读该位 |
| 退出自动存档 | 就地开关（按平台生效） |
| 删除游戏 | 危险项：**要按两次 A** 才真删，B 取消 |

> 弹层是模态的：它开着的时候只有 A / B / 方向有效，Y、START、L1/R1 全部被吞掉，不会漏到背后的界面。
> 「保存存档」**不在**前端 —— 前端是启动器，不在游戏现场，存不了档。存档请用下面的 M + R1。

## 二、游戏里（RetroArch）

> ★ **所有组合键都要先按住 M 键**（机身中间那个，出厂门禁 `input_enable_hotkey_btn = "10"`），
> 再按另一个键。直接单按 A / B / START 只会喂给游戏本身。

| 组合 | 作用 |
| --- | --- |
| **M + A** | 暂停 / 继续 |
| **M + B** | 重置游戏（回到开机画面，**不退出**） |
| **M + START** | 退出游戏，回到 LANGOS 前端 |
| **M + X** | 打开 / 关闭 RA 菜单（金手指、核心选项、存档位、连发都在这） |
| **M + R1** | 存档（存到当前存档位） |
| **M + L1** | 读档 |
| **M + L2** | **快进**（按住不放，松开即恢复原速） |
| **M + R2** | **快进**（按一下锁住，再按一下取消） |
| **M + 十字键上 / 下** | 屏幕亮度 + / − |
| 同时按 L3 + R3 | 出厂另外配的「开 RA 菜单」组合，备用 |

**下面这些没有绑手柄按键**，只有键盘（掌机没键盘，等于用不了）：

| 功能 | 键盘键 |
| --- | --- |
| 慢动作（按住） | E |
| 倒带 | R |
| 逐帧 | K |
| 金手指 开关 / 下一条 / 上一条 | U / Y / T |
| 截图 | 未绑定 |

**音量不归 RA 管** —— 用机身上的音量键（见第三段）。RA 配置里 `volume_up_btn` / `volume_down_btn` 都是 `nul`。

> **快进是 2026-09-16 才加到 L2 / R2 上的**（原本 L2 / R2 是亮度，亮度挪到了十字键上 / 下）。
> RA 的快进属于**热键**，必须挂在门禁键后面，所以按法是 `M + L2` 而不是单按 L2。
> 那次改的**只有** `hold_fast_forward` / `toggle_fast_forward` / `brightness_up` / `brightness_down`
> 四项，门禁 `input_enable_hotkey_btn` 始终是出厂的 `"10"`（M）—— 所以上面整套 `M + XXX` 一个都没动。
> 铁律仍然成立：**前端一个 RA 热键的字节都不写**，改的是设备上的 `retroarch.cfg`。

## 三、系统级（ogage 全局热键，任何界面都生效）

| 按键 | 作用 |
| --- | --- |
| **电源键** 短按 | 真待机（suspend，屏幕关、机器省电；再按任一键唤醒） |
| **电源键** 长按 | 关机（先播 2 秒关机动画，再断电） |
| **音量 ＋ / －** | 系统主音量加减（游戏内外都生效） |
| 插耳机 | 自动切音频输出（扬声器 ↔ 耳机，由 rk-headset 事件触发） |

自动行为：**无操作 10 分钟**（且没在充电、没在玩游戏）→ 自动进真待机。

厂商另留了两个开关文件（要 root 改，LANGOS 默认都不存在）：

| 文件 | 存在时的效果 |
| --- | --- |
| `/home/ark/.config/.SWAPVOLUMEBUTTONS` | 音量键改成调**亮度** |
| `/home/ark/.config/.SWAPPOWERANDSUSPEND` | 电源键短按 = 关机、长按 = 待机（与出厂相反） |

## 四、几点说明

- **出不来游戏怎么办**：先按住 M 再按 START。这是唯一可靠的退出口，前端在游戏里不响应任何按键。
- **RA 菜单里改的东西**（金手指、核心、遮罩、连发）是 RA 自己的存档，跟前端无关；
  前端弹层里的核心 / 着色器 / 存档位是**启动参数**，只影响"下次怎么启动这个游戏"。
- **前端接管的启动链路**：前端按下"启动游戏"后自己退出，屏幕交给 RetroArch；游戏退出后启动器再把前端拉起来。
  所以游戏中看到的画面全是 RA 的，前端设置页按不出来。
- **SELECT 退出前端**这个功能 2026-09-15 已经撤掉（前端接管链路后，退出去只会被原地拉起、白丢续页状态）。
  真要退出/关机走「设置 → 电源 / 退出」。
